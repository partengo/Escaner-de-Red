#Escaner-de-Red

## Funcionalidades
- Escaneo por ping de rango IP
- Obtención de nombre de host
- Interfaz gráfica amigable (Swing)
- Exportación de resultados
- Orden y filtrado

## Requisitos
- JDK 11+
- Conexión de red local

## Cómo usar
1. Ejecuta `MainApp.java`
2. Ingresa IP de inicio y fin
3. Presiona "Escanear"
